# 視点 (Perspective)
PC が「誰がどの役職である可能性がどれだけ残っているか」を保持する仕組み。  
人狼ゲームの進行（CO・占い結果・襲撃・追放など）によって更新され、仲間度算出やアクション選択の基盤となる。

## TL;DR（最重要ポイント）
- **視点オブジェクト**は「役職可能性の割合」を保持するデータ構造。  
- 各キャラは **自役職視点** と **CO役職視点** の二重構造を持ち、状況に応じて使い分ける。  
- **共通視点**は全体の最大公約数的な視点。破綻するとゲーム続行不可能（＝「水そうめん」状態）。  
- **破綻**は「論理的に矛盾が生じたとき」に発生。以降は「そのキャラ＝人狼陣営」と確定する。  
- 仲間度計算には、行動内容に応じて **CO視点 or 自役職視点** を利用。  


## データ構造（サンプル）
- キャラクターIDごとに役職の可能性を 割合（0〜1） で保持。
- uncertified は「残り未確定の役職数」を保持する特殊キー。
```
{
    "zundamon": {"werewolf":1,"fortuneTeller":0,"villager":0,"madman":0},  
    "metan":    {"werewolf":0,"fortuneTeller":0.5,"villager":0,"madman":0.5}, 
    "tsumugi":  {"werewolf":0,"fortuneTeller":0,"villager":1,"madman":0},   
    "hau":      {"werewolf":0,"fortuneTeller":0.5,"villager":0,"madman":0.5},   
    "ritsu":    {"werewolf":0,"fortuneTeller":0,"villager":1,"madman":0},     
    "uncertified":{"werewolf":0,"fortuneTeller":1,"villager":0,"madman":1}
}
```

## 各視点の種類と仕様

### 1) 自役職の視点 (`rolePerspective`)
- そのキャラ自身だけが知っている確定情報を含む。  
- 例：自分の役職、真占い師なら占い結果。  
- **投票先の決定**で参照される。

### 2) CO役職の視点 (`perspective`)
- 表向きの CO に基づいた視点。  
- **アクション選択時に参照される。**
- 真役職なら自役職視点と同一。  
- 偽役職なら自役職視点と矛盾する値を持つこともある。  
- 複数占COが出た場合は「自分以外の占COは狼か狂」といった視点を構築。

### 3) 共通視点 (`commonPerspective`)
- 観戦者的な、最小限の確定情報だけを反映した最大公約数的視点。  
- 各キャラ視点よりも情報量が少ない。  
- 破綻すると「水そうめん」状態となり、ゲーム進行不可。  

## 破綻 (Contradiction)

### 定義
- 視点オブジェクト更新の結果、「あるキャラがどの役職でもありえない」状態になること。  

### 典型例
- 占COが3人いる状況で、非占CO者に●を出した → 破綻。  
- ●を出したキャラが襲撃された → 破綻。  
- ●を出されたキャラが追放されてもゲームが続行 → 破綻。  

### 効果
- 他キャラの視点で「破綻したキャラは人狼陣営確定」となる。  
- 論理力が高いキャラほど強く反応して疑い・投票に反映。  
- **信頼度は変化しない**ため、ポンコツ挙動が残る。  

### 共通視点の破綻
- 共通視点が破綻＝**ゲーム進行不能**。  
- 内部では「水そうめんアラート」が発生。バグ扱いで報告推奨。  

## 仲間度との関係
- アクション選択：**CO役職視点 × 信頼度** を用いる。  
- 投票選択：**自役職視点 × 信頼度** を用いる。  
- よって、人狼陣営は「村人のフリをしつつ投票だけは仲間を守る」という挙動を再現できる。  
- 「投票先は嘘をつかない」と言われる所以。  

## 同陣営割合
- 視点オブジェクトにおいて「自分と同陣営の役職割合の合計値」。  
- 値域：
  - 1.0 = 常に仲間  
  - 0.0 = 常に敵  
  - 中間値 = 未確定
